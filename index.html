DeepSeek 接口设置

备份与恢复（重要）

数据存在浏览器里。建议每周导出一次备份，放到 D:\看书笔记\知识库工具\ 下面。

手机 ↔ 电脑 搬运数据

手机上记完点「复制数据」→ 粘到微信「文件传输助手」发给自己；换到另一台设备后点「粘贴数据合并导入」，两边数据会自动合起来（按内容去重，不会互相覆盖）。反向也一样。

在手机上记录（凑合可用版）

  1. 把文件装进手机：把 个人知识库.html 发到微信「文件传输助手」发给自己 → 手机上点开这个文件 → 右上角「用其他应用打开」→ 选一个浏览器（Chrome / Safari / 夸克都行）。
  2. 做成"App"：在浏览器里点「分享」→「添加到主屏幕」。以后从桌面图标打开，和 App 一样。
  3. 随时记：用「随手记」或「粘贴导入」记东西，和电脑上完全一样。
  4. 搬回电脑：记完点本页「复制数据到剪贴板」→ 发到微信「文件传输助手」；电脑上打开工具 →「粘贴数据合并导入」→ Ctrl+V → 合并导入。
  5. 记住一件事：两台设备不会自动同步，不主动搬运就是各记各的。建议固定「手机随手记 → 晚上回电脑合并」这个节奏。
为什么这么麻烦：这是纯本地网页，数据存在每台设备各自的浏览器里，不经过任何服务器——好处是不用注册、不用联网、没人能看到你的笔记；代价就是设备之间要你手动搬一次。

使用说明（照着做就行）

  1. 不买 API 也能用：三个 AI 环节都有「手动模式」——复制提示词 → 粘到 DeepSeek 官网/App 对话框 → 把它的回答粘回工具。完全免费，效果一样。
  2. （可选）装 Key：想让工具自己跑的话，去 platform.deepseek.com 注册，创建 API Key 填到上面，点保存设置、再点测试连接（显示出模型列表就算通）。
  3. 导入老笔记：到「① 采集」，把 D:\看书笔记\理财 里的 docx 拖进去，确认入库。
  4. 每天 2 分钟：想到什么就写到「随手记」，或者把微信读书里新的划线复制粘贴进来。
  5. 整理笔记：到「② 知识库」点「AI 批量结构化」；没 Key 就点旁边的「批量提示词（手动模式）」，一次 10 条。
  6. 看画像：到「③ 我的画像」点「从我的随笔自动填充」保存文风样本，再用「AI 直接生成」或「复制提示词（手动模式）」得到画像并存档。
  7. 写文章：到「④ 内容生成」填主题 → 检索素材 → 生成初稿 → 复制到公众号后台排版发布。
  8. 每周备份：到本页点「导出备份 JSON」，存到 D:\看书笔记\知识库工具\。
三个 AI 按钮报错（网络或跨域）怎么办：直接用旁边的「手动模式」。单条结构化用笔记卡片上的「手动」，批量用「批量提示词（手动模式）」，画像和写作各有自己的「复制提示词（手动模式）」。
